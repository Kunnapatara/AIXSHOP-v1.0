# AI Studio Working Archive (`docs/archive/aistudio`)

This directory contains preserved historical planning notes and sample Shopify product catalog transcripts exported during the initial prototyping phase of **AIXSHOP v1.0**.

## Disposition & Governance

- **Preservation Status**: Retained read-only for audit traceability and historical provenance.
- **Runtime Exclusion**: None of the files in `docs/archive/aistudio/` are imported by application source code (`src/`, `server.ts`), bundled by Vite (`dist/`), or served over HTTP by Express.
- **Data Provenance**: Sample catalog transcripts (e.g., `Allbirds_Shopify_products_fdd9af86.txt`) reflect historical exploratory fixtures only and do not represent live customer connections or production store credentials.
